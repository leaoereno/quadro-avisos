⚙ Configuracao da API ✓ Salvo

A configuracao e salva no navegador (localStorage) e preenchida automaticamente nos campos de todos os endpoints. Para ambientes com API Gateway ou MCP, informe a URL base completa do gateway. O token e enviado como Authorization: Bearer <token> e tambem como X-Api-Token em todas as requisicoes.

Quadro de Avisos — REST API

API para integracao de fontes externas com o modulo de avisos do Zabbix. Permite consultar e publicar avisos a partir de ferramentas como Grafana, ServiceNow, scripts de monitoramento ou qualquer sistema HTTP.

Zabbix 7.0 LTS REST / JSON Bearer Token

Autenticacao

Bearer Token

Configure o token no painel acima. Ele sera enviado automaticamente em toda requisicao via dois headers simultaneos para maxima compatibilidade com gateways:

Authorization: Bearer <token>
X-Api-Token:    <token>

Tipos de Aviso

O campo tipo_borda define a cor e semantica do card no dashboard.

info success warning danger mudanca evento
ValorSemanticaCor
infoAvisos informativos gerais● Azul
successIncidente resolvido, conclusao● Verde
warningAtencao, degradacao parcial● Amarelo
dangerCritico, urgente, indisponibilidade● Vermelho
mudancaRequisicao de mudanca (RFC)● Roxo
eventoEvento programado, manutencao● Ciano
GET /api/avisos Lista avisos com filtros e paginacao ▼
Query Parameters
ParametroTipoObrig.Descricao
tipo_bordastringopcionalFiltra por tipo. info|success|warning|danger|mudanca|evento
statusstringopcionalactive|scheduled|expired
usrgrpidintegeropcionalAvisos visiveis para o grupo (inclui para_todos)
limitintegeropcionalMax registros. Padrao: 50, Max: 200
offsetintegeropcionalDeslocamento para paginacao. Padrao: 0
orderstringopcionalcriado_em_desc|criado_em_asc|inicio_asc|fim_asc
Exemplo
curl
curl -X GET \
  "https://api-gw/api/?tipo_borda=danger&status=active" \
  -H "Authorization: Bearer <token>" \
  -H "X-Api-Token: <token>"
Respostas
200Lista retornada com sucesso▼
{
  "success": true,
  "data": [ { "id": 42, "titulo": "Manutencao", "tipo_borda": "danger", "status": "active", /* ... */ } ],
  "pagination": { "total": 1, "limit": 50, "offset": 0, "pages": 1 }
}
401Token invalido▶
{ "success": false, "error": { "code": "UNAUTHORIZED", "message": "Invalid or missing API token." } }

          POST
          /api/avisos
          Cria um novo aviso
          ▼
        

        

          
Request Body — application/json

          

            
CampoTipoObrig.Descricao

            
              
titulostringobrigatorioTitulo. Max 255 chars.

              
conteudostringobrigatorioCorpo em Markdown ou HTML.

              
tipo_bordastringobrigatorioinfo|success|warning|danger|mudanca|evento

              
criado_porintegerobrigatoriouserid do Zabbix responsavel.

              
iniciostringobrigatorioISO 8601: 2025-06-01T08:00:00

              
fimstringobrigatorioISO 8601. Deve ser posterior a inicio.

              
usrgrpidintegercondicionalID do grupo. Obrigatorio se para_todos=false.

              
para_todosbooleanopcionalVisivel para todos os grupos. Padrao: false.

              
sourcestringopcionalIdentificador da fonte. Ex: "grafana", "servicenow". Max 64 chars.

            
          


          
Exemplo

          

            
curl

            
curl -X POST "https://api-gw/api/" \
  -H "Authorization: Bearer <token>" \
  -H "Content-Type: application/json" \
  -d '{
    "titulo": "Manutencao BD producao",
    "conteudo": "## Impacto\nIndisponibilidade de **15 min**.",
    "tipo_borda": "evento",
    "criado_por": 1,
    "usrgrpid": 7,
    "para_todos": false,
    "inicio": "2025-06-10T02:00:00",
    "fim": "2025-06-10T03:00:00",
    "source": "servicenow"
  }'

          


          
Respostas

          

            
201Aviso criado com sucesso▼

            
{ "success": true, "data": { "id": 43, "status": "scheduled", /* ... */ } }

          

          

            
422Erro de validacao▶

            
{
  "success": false,
  "error": { "code": "VALIDATION_ERROR", "message": "Request validation failed." },
  "errors": [ { "field": "titulo", "message": "Required field." } ]
}

Schema — Aviso

      
json schema

        
{
  "id":            integer
  "titulo":        string
  "conteudo":      string           // Markdown ou HTML
  "tipo_borda":    string           // info|success|warning|danger|mudanca|evento
  "status":        string           // active|scheduled|expired (calculado)
  "usrgrpid":      integer|null
  "grupo_nome":    string|null
  "para_todos":    boolean
  "criado_por":    { username: string }
  "inicio":        string (ISO 8601)
  "fim":           string (ISO 8601)
  "criado_em":     string (ISO 8601)
  "atualizado_em": string (ISO 8601)
}

      

    


    

      
Schema — Error

      
json schema

        
{
  "success":   false,
  "timestamp": string (ISO 8601),
  "error": { "code": string, "message": string },
  "errors": [ { "field": string, "message": string } ]  // apenas em VALIDATION_ERROR
}
