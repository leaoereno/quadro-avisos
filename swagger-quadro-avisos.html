Quadro de Avisos — REST API

API para integração de fontes externas com o módulo de avisos do Zabbix. Permite consultar e publicar avisos a partir de ferramentas como Grafana, ServiceNow, scripts de monitoramento ou qualquer sistema HTTP.

Zabbix 7.0 LTS REST / JSON Bearer Token
Base URL
URL 
https://zabbix.suaempresa.com/zabbix/modules/quadro_avisos/api/
Formato de Resposta

Todas as respostas são application/json; charset=utf-8. Datas em ISO 8601 com timezone.

Autenticação

🔑

Bearer Token

Configure tokens no arquivo api/index.php na variável $API_TOKENS. Envie o token via header HTTP em cada requisição:

Authorization: Bearer seu-token-secreto
# Alternativa:
X-Api-Token: seu-token-secreto

Tipos de Aviso

O campo tipo_borda define a cor e a semântica do card exibido no dashboard do Zabbix.

info success warning danger mudanca evento
ValorSemânticaCor
infoAvisos informativos gerais● Azul
successIncidente resolvido, conclusão● Verde
warningAtenção, degradação parcial● Amarelo
dangerCrítico, urgente, indisponibilidade● Vermelho
mudancaRequisição de mudança (RFC)● Roxo
eventoEvento programado, manutenção● Ciano
GET /api/avisos Lista avisos com filtros e paginação ▼
Query Parameters
ParâmetroTipoObrig.Descrição
tipo_borda string opcional Filtra por tipo. info | success | warning | danger | mudanca | evento
status string opcional Filtra por status temporal. active | scheduled | expired
usrgrpid integer opcional Retorna avisos visíveis para o grupo (inclui para_todos)
para_todos boolean opcional Se true, retorna apenas avisos visíveis para todos os grupos
limit integer opcional Máximo de registros por página. Padrão: 50, Máx: 200
offset integer opcional Deslocamento para paginação. Padrão: 0
order string opcional Ordenação. criado_em_desc | criado_em_asc | inicio_asc | fim_asc. Padrão: criado_em_desc
Exemplo de Requisição
curl 
curl -X GET \
  "https://zabbix.suaempresa.com/zabbix/modules/quadro_avisos/api/?tipo_borda=danger&status=active&limit=10" \
  -H "Authorization: Bearer seu-token-secreto" \
  -H "Accept: application/json"

          POST
          /api/avisos
          Cria um novo aviso
          ▼
        

        


          
Request Body — application/json

          

            
CampoTipoObrig.Descrição

            
              

                titulo
                string
                obrigatório
                Título do aviso. Máx 255 caracteres.
              

              

                conteudo
                string
                obrigatório
                Corpo do aviso em Markdown ou HTML.
              

              

                tipo_borda
                string
                obrigatório
                Tipo/cor do card. info | success | warning | danger | mudanca | evento
              

              

                criado_por
                integer
                obrigatório
                userid do Zabbix responsável pelo aviso.
              

              

                inicio
                string
                obrigatório
                Início da exibição. ISO 8601: 2025-06-01T08:00:00
              

              

                fim
                string
                obrigatório
                Fim da exibição. ISO 8601. Deve ser posterior a inicio.
              

              

                usrgrpid
                integer
                condicional
                ID do grupo destinatário. Obrigatório se para_todos for false.
              

              

                para_todos
                boolean
                opcional
                Se true, o aviso é visível para todos os grupos. Padrão: false.
              

              

                source
                string
                opcional
                Identificador da fonte remota. Ex: "grafana", "servicenow", "pagerduty". Máx 64 chars.

Schema — Aviso

      

        
json schema

        
{
  "id":            integer          // ID único
  "titulo":        string           // Título do aviso
  "conteudo":      string           // Markdown ou HTML
  "tipo_borda":    string           // info|success|warning|danger|mudanca|evento
  "status":        string           // active|scheduled|expired (calculado)
  "usrgrpid":      integer|null     // ID do grupo destinatário
  "grupo_nome":    string|null      // Nome do grupo (ou "All groups")
  "para_todos":    boolean          // Visível para todos os grupos
  "criado_por":    { username: string }
  "inicio":        string (ISO 8601)
  "fim":           string (ISO 8601)
  "criado_em":     string (ISO 8601)
  "atualizado_em": string (ISO 8601)
}

      

    


    

      
Schema — Error

      

        
json schema

        
{
  "success":   false,
  "timestamp": string (ISO 8601),
  "error": {
    "code":    string   // UNAUTHORIZED | NOT_FOUND | VALIDATION_ERROR | INTERNAL_ERROR
    "message": string
  },
  "errors": [  // apenas em VALIDATION_ERROR
    { "field": string, "message": string }
  ]
}
